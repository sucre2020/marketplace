## Project: Leather Works Market Place Web App

* This project represents my goal of growing as a software engineer by building a real-world web application that solves practical problems for local leather works artisans. Through this project, I aim to strengthen my skills in backend development, database design, web application architecture, problem solving, and full-stack software engineering.

* The platform is being designed as an online marketplace where artisans who create leather products such as shoes, bags, belts, wallets, and other handmade items can showcase their products and connect with customers digitally. My objective is not only to build a functional application, but also to understand how scalable web systems are planned, developed, tested, and improved over time.

* To accomplish this, I will be using Django as the primary framework for the project. Since Django is new to me, this project will also serve as a hands-on learning experience where I will learn and apply concepts such as models, views, templates, routing, authentication, CRUD operations, and relational database management. 

* I intend to approach the development process incrementally by first building a Minimum Viable Product (MVP) with core functionality such as user registration, artisan profiles, product listings, and search features. After establishing a stable foundation, I plan to expand the application with more advanced features including improved UI/UX, marketplace functionality, cloud deployment, and possible payment integration.

* Beyond technical development, this project is also an opportunity for me to improve collaboration, project planning, documentation, and software engineering discipline by consistently sharing progress, learning new technologies, and applying best practices throughout the development process.

### Development Environment

**Several tools and technologies will be used throughout the development of this software project to support planning, coding, testing, database management, and deployment preparation.**

* Visual Studio Code (VS Code) will serve as the primary code editor for writing and organizing the project files.
* Git and GitHub will be used for version control, source code management, and tracking project progress.
* Django will serve as the main web development framework for building the backend logic and application structure.
* SQLite or MongoDB will be used during development.
* HTML/CSS and a bit of JavaScript will help design and improve the frontend user interface.
* The Django Admin Panel will assist with managing application data during development and testing.
* Web browsers such as Brave, Google Chrome or Firefox will be used for testing and debugging the application.
* Python virtual environments will help manage project dependencies and packages.

### Additional Tools

* Terminal/Command Line tools will be used to run the development server, execute migrations, and manage the project environment.
* Documentation resources and online tutorials will support learning Django concepts and solving development challenges throughout the project.


### Programming Language Used

The primary programming language for this project will be Python.

Python was selected because it is beginner-friendly, powerful, and widely used in web development and software engineering. It works effectively with the Django framework and allows developers to build secure, scalable, and maintainable web applications efficiently.

**Python will be used to:**

* Build backend application logic
* Create database models
* Handle user authentication
* Process requests and responses
* Manage routes and views
* Implement CRUD operations
* Connect the application to the database

In addition to Python, the project will also use:

* HTML for structuring web pages
* CSS for styling and layout
* JavaScript for basic frontend interactivity
* SQL or MongoDB for databases
